## Features

- ⚡ **Fast C++ core** with Python bindings
- 🔢 **Linear algebra primitives** (Vector, Matrix)
- 🤖 **K-Nearest Neighbors classifier**
- 📊 **Performance metrics** (accuracy, MSE)
- 🐍 **Numpy-compatible API**
